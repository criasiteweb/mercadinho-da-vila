# Mercado Já — briefing do Matheus

Aberto em 29/09/2026. Projeto novo, **não** é o mercado-modelo (Mercado Bom Preço).
Este aqui é feito do zero, com proposta visual própria.

## Nome e marca
- Nome: **Mercado Já**
- Logo pode ser ilustrativo, só para apresentar. Não é a marca final.

## Visual
- Tem que ser **diferente de todos**. Nada de cara de supermercado comum.
- Muito interativo com o cliente.
- **Imagens em movimento**, letras que se mexem, animação como parte do site.
- **Fundo branco** com **cor viva** de destaque.
- Pesquisar referências atuais antes de propor, não repetir o que já foi feito.

## Organização, o ponto central
A organização tem que ser única. Este mercado tem áreas que funcionam separadas:

1. **Adega** — separada
2. **Ração / pet** — separada
3. **Padaria** — separada
4. Mercado geral (o resto)

Não é só categoria dentro do mesmo catálogo. São ambientes com identidade própria
dentro do mesmo site.

## O diferencial de venda
- **O mercado entrega.** Esse é o diferencial que o site precisa gritar.

## Sistema, além da vitrine
- Controle de **estoque**
- **Caixa**
- Painel de pedidos e entrega
